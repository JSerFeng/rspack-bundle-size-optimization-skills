# 普通用户报告模板

用 HTML 简化用户理解成本，语言保持通俗易懂，每一个优化要详细解释背后的原理，按照每一个优化项一个一个介绍背景，优化的收益，优化的方式，单位用 Kb，降低幅度要计算相比 base 的百分比。

## 落地的修改

每项修改使用相同的五行结构，保持问题与收益一一对应：

### 修改名称

- **原来的问题：** 用普通语言描述为什么多加载或多生成了代码。
- **实际修改：** 指出改动的文件和行为，不贴大段源码。
- **实际收益：** 写该项独立生产 A/B 的原始字节数、gzip，以及适用的请求结果。
- **为什么有效：** 一句话解释代码与产物变化的因果关系。
- **验证：** 列出生产构建的检查结果。

## 正文语言规则

正文避免互联网行业黑话。

### 精确测量

每个统计范围的精确体积，单位 Kb、gzip 字节数和资源数量；
