# ECMAScript Target Analysis

Read this reference when an ECMAScript or browser target is the tested bundle
variable.

Attribute the size change by separating:

- polyfill assets and modules;
- added and removed modules;
- changed generated bytes for modules common to both builds;
- loader, transpiler, and runtime-helper output;
- chunk membership and concatenation changes.

Inspect pre- and post-loader source for the largest changes. Label any
remainder whose source-map or per-module evidence is incomplete. Keep the
target change within the user's browser-support requirements and confirm its
result with otherwise comparable production assets.
